2. Quick Start Guide

  1. Install the extension from the Chrome Web Store and click the Extensions (puzzle piece) icon in the top-right corner of Chrome.
  2. Pin Walkthrough Scout to your toolbar for one-click access while prospecting.
  3. Click the extension icon to open the popup and sign in or launch your outbound prospecting workflow.
  4. Refresh any active browser tab after first installation so the extension scripts load properly.

3. Troubleshooting & Frequently Asked Questions

The extension isn't capturing data on a page

Make sure you have refreshed the page after installing or updating the extension. Chrome extensions cannot run on restricted browser pages such as chrome:// URLs or the Chrome Web Store itself.

How do I update to the latest version?

Chrome updates extensions automatically. To force an immediate update, open chrome://extensions, toggle on Developer mode in the top right, and click Update.

How do I uninstall or remove my local data?

Right-click the Walkthrough Scout icon in your Chrome toolbar and select Remove from Chrome. Removing the extension deletes all locally stored extension settings from your browser. For account or billing deletion, email floyd@seamlessoutbound.com.

4. Reporting a Bug

If you run into an issue, email floyd@seamlessoutbound.com with:

  • Your Chrome browser version (found at chrome://version)
  • A brief description of the steps that triggered the issue
  • Any error message displayed in the extension popup
